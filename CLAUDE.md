# Repositório de estudo de Machine Learning

Objetivo: aprender ML, dos fundamentos a tópicos avançados. Nada de app/produto; só material de estudo.

- Módulos numerados na raiz (`00-...`, `01-...`), cada um com `README.md` e subtópicos em subdiretórios (`kebab-case`). Novos tópicos seguem `_template/`.
- C++ (C++17+, sem dependências pesadas) para algoritmos puros implementados do zero; Python para demonstrar bibliotecas prontas em tópicos difíceis de fazer em C++.
- Conceitos explicados em Markdown, em português, com intuição + matemática + código.
- Ao adicionar conteúdo, atualize o `README.md` do módulo.
